Ambiente de Desenvolvimento:
- IDE: Keil µVision;
- Linguagem: C.

Hardware Necessário:
- Microcontrolador AT89S52;
- Display Alfanumérico LCD 16x2 (Controlador HD44780 ou compatível);
- Display Gráfico GLCD 128x64 (Controlador ST7920);
- Teclado Matricial.

T-Rex:
- Sobreviva saltando e desviando dos obstáculos. A velocidade aumenta a cada 50 pontos;
- Saltar: Aperte o Botão 8 (Linha 3, Coluna 2).

Stock Car:
- Mantenha-se na pista e desvie dos carros inimigos. A velocidade aumenta a cada 100 pontos;
- Iniciar Jogo: Aperte o Botão 1 (Linha 1, Coluna 1);
- Mover Esquerda: Aperte o Botão 4 (Linha 2, Coluna 1);
- Mover Direita: Aperte o Botão 6 (Linha 2, Coluna 3);
- Para o Stock Car, aperte e solte os botões para cada movimento.

Como Executar:
- Crie um projeto no Keil, inclua o arquivo .c e compile para gerar o arquivo .hex;
- Utilize um gravador ISP para gravar o arquivo .hex no microcontrolador.
