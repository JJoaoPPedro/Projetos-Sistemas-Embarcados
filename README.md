# Projetos-Sistemas-Embarcados
Projetos criados durante a disciplina de Projeto de Sistemas Computacionais Embarcados por João Pedro Machado de Almeida e Nicolas Henrique Fernandes da Silva.
Para o desenvolvimento foram utilizadas as linguagens Assembly e C, e os códigos foram escritos para um microcontrolador AT89S52, contido em uma placa de desenvolvimento e interligado a vários outros periféricos via seus pinos.
